# EduSmart AI — Synthetic Holdout Evaluation

**Experiment date:** 2026-10-16  
**Training script:** `ml/train_model.py`  
**Dataset:** 1,200 synthetic records generated with seed 42  
**Split:** 80% training (960 records), 20% test (240 records), stratified; `random_state=42`  
**Model:** `RandomForestClassifier`, 40 trees, `max_depth=6`, `min_samples_leaf=4`, `random_state=42`

This is a reproducible evaluation of the prototype training experiment, not an evaluation on real student records. Updating project documentation does not imply that the experiment was rerun.

## Interpretation and limitations

Labels in this synthetic dataset are generated by a hand-written formula using attendance, average marks, recent trend and missed assessments. The holdout evaluation measures how well the model learns that synthetic labeling rule on a held-out subset.

It does **not** establish real-world academic-risk accuracy, fairness, calibration, or usefulness. The frontend's tree-vote fraction for the selected class is not a calibrated probability. Predictions are demonstrative indicators and must not be used as the sole basis for decisions about students.

## Requirements for future research evaluation

- Use an institution-approved, privacy-protected dataset and minimize personally identifiable information.
- Define labels independently of the same formula used to generate input features.
- Document missing-data handling, class balance, leakage checks and split methodology.
- Compare with simple baselines and report per-class precision, recall, F1 and confusion matrix.
- Assess subgroup fairness and calibration before considering real-world use.
- Clearly document consent, data governance, limitations and intended human oversight.
