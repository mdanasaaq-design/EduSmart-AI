# EduSmart AI — Synthetic Holdout Evaluation

**Evaluation date:** 2026-10-16  
**Training script:** `ml/train_model.py`  
**Dataset:** 1,200 synthetic records generated with seed 42  
**Split:** 80% training (960 records), 20% test (240 records), stratified; `random_state=42`  
**Model:** RandomForestClassifier with 40 trees, max_depth=6, min_samples_leaf=4, random_state=42

## Important limitation

These results are from a deterministic synthetic dataset whose labels are generated by a hand-written formula using attendance, average marks, recent trend and missed assessments. This evaluation checks that the model learns that synthetic labeling rule on a held-out subset. It **does not establish real-world academic-risk accuracy, fairness, calibration, or usefulness**. The displayed confidence in the web app is the fraction of exported trees voting for the selected class; it is not a calibrated probability.

For real research evaluation, use an institution-approved, privacy-protected dataset, define labels independently of the input formula, assess class imbalance and leakage, compare suitable baselines, and evaluate fairness before using predictions for decisions.
